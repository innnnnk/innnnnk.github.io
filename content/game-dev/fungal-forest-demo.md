## 设计原则

60 分钟版本不是"把 30 分钟版本拉长"，而是**在完整主干上嫁接两条可选支线**，让玩家有机会在主线之外"多待一会儿"——而这个"多待"的代价，是**对世界的理解更深，但身体更不安**。

> "认知的代价"在 60 分钟版本中不只是主题，而是**结构**：你越想知道真相，你在森林里停留越久，你看到的"不对"就越多。

---


## 背景

Project_DND 目前卡在场景搭建阶段。Demo 需要一个能展示核心玩法（自由探索 + 回合制战斗 + 2.5D 美术风格）的展示场景。

场景主题：**真菌森林（Fungal Forest）**。

**预计体验时长：30-60 分钟（主线 ~30min，全探索 ~60min）**（关键路径叙事 ~730s + 两场战斗 + 探索走动）。

---


## 空间结构：珠串式布局

Demo 场景采用**线性珠串结构**——6 个精心编排的区域沿一条主路径串联，而非开放世界：

```
🌿入口 → 🍄走廊 → ⚔小战 → 🌑峡谷 → 👑BOSS → ✨结尾
 好奇     沉浸     紧张     压抑     高潮     释放
```

### 为什么不是开放区域？

1. **引导可控** — 确保 Demo 玩家在 30-60 分钟（主线 ~30min，全探索 ~60min）内看到所有精彩内容
2. **资产需求低** — 不需要填充 360° 视野，只需打磨可见路径
3. **节奏可控** — "下一个转角有什么"比"随便逛逛"更有驱动力


## 与 30 分钟版本的关系

```
60分钟版本 = 30分钟版本（完整主干：A→B→C→D→E→F）
           + 支线1：回声裂隙
           + 支线2：孢子平台
           + 恢复被 30 分钟版本砍掉的内容
```

两条支线都是**完全可选**的。玩家可以一路直奔 Boss，在 30 分钟内通关；也可以探索支线，把体验拉到 50–60 分钟。

60 分钟版本在 30 分钟版本基础上**恢复**以下内容：

| 内容 | 30分钟版本 | 60分钟版本 |
|---|---|---|
| 法师职业 | ❌ 暂锁 | ✅ 开放（2 戏法 + 1 个 1 环法术/场战斗） |
| 同伴 AI 性格签名 | ❌ 只保留默认台词 | ✅ 识别动画 + 哈洛德条件台词分支 |
| Boss 战斗日志 | 3 条替换 | ✅ 5 条完整不可理解化 |
| 孢子云记忆文本 | ❌ 纯机制 | ✅ 3 段淡金色文本 |
| D 区底座阴影抖动 | ❌ 去掉 | ✅ 每 30 秒随机抖动 |
| 同伴质问委托人 | ❌ 去掉 | ✅ 保留（F 区：「多出来的那个人是谁？」） |
| 铭牌计数器视觉污染 | ❌ 去掉 | ✅ 第 5 块→抖动 / 第 8 块→淡紫 / 第 11 块→缓慢呼吸式闪烁（三周期，淡紫） |

## 三种玩家类型的节奏

60 分钟版本的结构带有自适应的特性——不同类型的玩家会自然找到自己的节奏，不需要强制引导。

### 类型 A：探索型（55–65 min）

```
A 区：3 min — 异常蘑菇 + 发现回声裂隙入口
  ↓ 进入支线1：回声裂隙（~12 min）
B 区：5 min — 仔细阅读日记 + 搜索营地 + 营救同伴
C 区：6 min — 战斗 + 听同伴完整台词
D 区：4 min — 观察螺旋纹路 + 拾取铭牌 + 阴影抖动
  ↓ 发现孢子平台岔路
  ↓ 进入支线2：孢子平台（~7 min，听完 3 段文本）
E 区：15 min — Boss 四阶段 + 孢子云记忆文本
F 区：3 min — 同伴质问委托人 + 黑屏便签
合计：55 min
```

### 类型 B：战斗型（35–40 min）

```
主线快速通关（~26 min）+ 可能发现一条支线（+10 min）→ ~36 min
```

### 类型 C：速通型（25–30 min）

```
直奔主线，忽略所有可交互物，只打强制战斗
```

**三种类型都能在 Demo 中找到自己的节奏。** 可选的深度，而非强制的长度。

## 设计要点

### 空间节奏：同一条路，六种感受

核心技巧是**改变宽度、曲率和围合感**：

- **A 入口** — 开阔椭圆，给人安全感。但**出生点前方 8m 处有一棵倒下的蘑菇**——菌盖朝向玩家来时的方向，不是朝上。这是玩家遇到的第一个"不对劲"。靠近按 E，角色底座阴影闪烁一次，根据身份说出不同台词。
- **B 走廊** — S 形弯道，激发好奇心（"拐角后面是什么？"）
- **C 空地** — 突然开阔 + 障碍物 → 警觉 → 战斗触发
- **D 峡谷** — 笔直收窄，两侧高墙，压抑→前方有光→必须前进。玩家静止时，底座阴影偶尔轻微抖动。
- **E 竞技场** — 圆形闭合空间，无处可逃
- **F 出口** — 重新开阔，暖光，但结尾不是"胜利释放"——是"你走出森林，数了数铭牌，十二块。你明明记得只捡了十一块。"

### 光照梯度

从暖到冷再到暖的完整弧线：

- A: 暖色夕阳 God Rays → B: 冷色荧光渐显 → C: 均匀中性战斗光
- D: 最暗，纯荧光照明 → E: 戏剧化强对比 → F: 暖金色胜利光

### 生态梯度：青苔 → 腐木 → 菌丝

八区不只是光在变——**生命也在渐变。** 从 A 区的正常森林到 E 区的真菌领地，再到 F 区的生机回归，生态和菌丝形成一条完整的渐变线：

| 区域 | 青苔/植被 | 腐木程度 | 菌丝浓度 | 生机感 |
|---|---|---|---|---|
| **A 入口** | 岩石覆青苔，地面稀疏杂草 | 少量枯枝落叶，正常森林 | 零星荧光小蘑菇，点缀性 | 🌱 正常森林 |
| **回声裂隙** | 少量青苔留在洞口，内部以菌丝为主 | 积水边有菌丝覆盖的岩面 | 洞壁菌丝脉络，较 B 区更密集 | 🌫 介于 A→B |
| **B 走廊** | 青苔变薄，仅岩壁阴暗面有小片 | 营地附近倒木，未腐烂 | 菌丝脉络开始出现在岩壁 | 🍂 生机退场 |
| **C 空地** | 几乎无青苔。地面灰白色干枯花草，低饱和度 | 中央大倒木，半腐，木纹变黑 | 菌丝宿主 + 倒木上大量菌丝 | 🦴 生机最低点 |
| **D 峡谷** | 岩壁光秃，无植被 | 无花草，地面碎石和泥土 | 菌丝嵌入岩壁裂缝，像血管 | 🩸 菌丝替代了青苔 |
| **孢子平台** | 无 | 无花草，被孢子云完全覆盖 | 浓密孢子云替代一切 | ☁ 介于 D→E |
| **E 王座** | 无 | 场地边缘有枯木残骸 | 全场菌丝饱和，地面蛛网状 | ⚫ 真菌领地 |
| **F 出口** | 青苔重新出现，地面稀疏杂草 | 倒木上长出新苔 | 菌丝淡化，只剩零星残留 | 🌿 生机回归（带异样） |

**设计原则：**

- 不是八套不同资产——是一套资产 + 区域参数。青苔/杂草用 Decal 或 Foliage 散布，按"生机指数"调密度和颜色饱和度
- 腐木是倒木资产的材质变体：A 区"正常枯木"材质 → C 区"半腐黑化"版本
- 花草在 C 区仍可存在，但颜色调为灰白低饱和（材质实例中调 Desaturation 参数）
- 菌丝从 B 区开始出现，逐区递增，到 E 区饱和——和"认知的代价"同步：你越深入、知道得越多，真菌越多、生命越少

**与光照的对应关系：**

| 区域 | 光照 | 生态 | 情绪共振 |
|---|---|---|---|
| A | 暖金夕阳光 | 青苔+杂草 | 温暖中有第一个"不对" |
| B | 暖光退→冷绿升 | 青苔变薄，菌丝初现 | 好奇转向沉浸 |
| C | 均匀中性战斗光 | 生机最低，腐木+低饱和花草 | 警觉、紧张 |
| D | 最暗，纯荧光 | 菌丝替代植被 | 压抑 |
| E | 戏剧化强对比 | 菌丝饱和，无植物 | 敬畏、高潮 |
| F | 暖金胜利光 | 青苔回归，菌丝残留 | 释然（带刺） |

**实现路径：** 同一种岩石资产在所有区域复用，A 区覆盖青苔 Decal，D 区换成菌丝 Decal——石头没变，变的是"现在谁在占据这块石头"。

### 源脉矿石：Demo 中的视觉锚点

源脉矿石（Sanguin Ore）是 Project_DND 世界观的核心物质——巨兽凝固的血。但目前在 Demo 中只有文本提及，没有视觉表现。本节定义源脉矿石的视觉设计和 Demo 植入点。

#### 视觉设计

| 属性 | 设计 |
|---|---|
| **基底** | 深灰-近黑的粗粝矿石，不规则几何体 |
| **纹理** | 天然切面上有发光的细密刻痕——晶体内部自己裂出的规则纹理，不是人工凿的。这些刻痕是**源脉文（Sanguin-Script）**的初始形态——巨兽思维脉冲在晶体结构中的天然印记 |
| **发光** | 裂痕中渗出微弱暖红色-暗橙色光（"血"的颜色）。不是霓虹亮——是余烬般的、深层的、脉动的暗光 |
| **脉动** | 靠近时，光有微弱明暗呼吸（心率节奏，不规律的规律）。玩家静止时更明显 |
| **触感暗示** | 表面是冷的，但裂缝里的光是暖的——"凝固的血，但里面还在动" |

#### 与菌丝荧光的视觉区分

Demo 中有两种发光物——**必须一眼可分**：

| | 菌丝 | 源脉矿石 |
|---|---|---|
| 颜色 | 冷绿-淡青（teal） | 暖红-暗橙（ember） |
| 发光方式 | 持续柔和荧光 | 脉动暗光，不规律 |
| 纹理 | 有机脉络 | 几何刻痕/晶面 |
| 情绪 | 真菌、异化、生长 | 古老、本源、血液 |

冷绿菌丝 + 暗红矿脉同时出现在画面里——视觉上已经在说"它们有关系但不同"。

#### Demo 植入点（三处最小改动）

**1. D 区岩壁 · 菌丝 + 矿石共生**

岩壁裂缝的菌丝交汇处，让墙壁局部裂开，露出小片暗红色晶体——源脉矿石原生面。菌丝从矿石裂缝中蔓延出来。不需要交互、不需要解释。玩家看到的画面是：**冷绿菌丝从暗红矿石裂缝中生出。**

**2. E 区场地中央 · 节点下的矿脉**

菌丝网络在地面中央收束为人形凹陷。凹陷底下的地面加一条细微暗红色裂隙——地底有东西在发光。和"真菌之主是第一滴源脉之血"的设定咬合。

**3. 晶核 · 裹着菌丝的源脉矿石碎片**

E 区击败后掉落的晶核，视觉上就是一块**被薄薄菌丝包裹的暗红色矿石碎片**。拿着它 = 拿着一块源脉矿石。F 区结尾"包裹里的晶石还是热的"有了视觉锚点。正式版中它是连接一切的关键道具：源脉文解读、菌丝感染追踪、觉醒共鸣系统的起始物。

#### 源脉矿石与 Demo 资产

| 编号 | 资产 | 用途 | 优先级 |
|---|---|---|---|
| ENV-D-ORE | 源脉矿石岩壁嵌块 | D 区岩壁裂缝中露出的矿石原生面，暗红晶体 + 菌丝蔓延 | P1 |
| ENV-E-ORE | 源脉矿脉裂隙（地面 Decal） | E 区菌丝节点下方，细微暗红色地裂发光 | P1 |
| ITEM-CORE | 晶核（裹菌丝的矿石碎片） | Boss 掉落物，可拾取，暗红脉动 + 薄菌丝层 | P0 |

### Encounter 设计

**小型遭遇（C 区）：** 2 只菌丝宿主 + 中央倒木掩体 → 教学性质的暖身战。同伴（矮人矿工）参与战斗，协助清小怪。环境叙事：空地边缘 2~3 个人面枯树桩（非战斗单位，注视行为详见「菌丝网络的场景展现」）。

**BOSS 战（E 区）：** 真菌之主（近战 AOE + 召唤 + 回血）+ 第 2 回合孵化 2 只小怪 + 动态孢子云（提供可移动隐形掩体）。Boss 战为四阶段动态结构——详见下方「Boss 战四阶段设计」。

## 支线1：回声裂隙（Echo Cleft）

### 位置与入口

A 区异常蘑菇旁，一个被菌丝半掩的岩石裂隙。裂隙入口只有 1.5m 高，玩家需要弯腰进入——相机自动降低 0.5m，暗示"你在进入另一个空间"。

**入口提示：** A 区异常蘑菇交互后，如果玩家在周围逗留超过 5 秒，底座阴影会朝裂隙方向微微偏移一次，随后恢复正常。玩家可能注意到，也可能错过。

> **设计说明：** 裂隙入口始终存在——不依赖异常蘑菇交互解锁。异常蘑菇的阴影偏移只是"提示"而非"钥匙"。玩家可以直接走进裂隙，错过蘑菇只意味着错过一个氛围细节，而非内容阻断。

### 空间

15×10m 的小型地下空间，天花板 2m，压抑。墙壁上有发光的菌丝脉络（复用 D 区岩壁材质）。中央有一个浅坑，坑底有积水。

### 敌人

| 敌人 | 数量 | 特性 |
|---|---|---|
| 菌丝幼体 | 3 只 | 比 C 区菌丝宿主弱（HP -30%），但会群体行动——一只发现玩家后，另外两只从侧面包抄 |
| 回声宿主 | 1 只 | 精英菌丝宿主。外观与普通宿主相同，但**胸口嵌着一块发光的铭牌**。额外技能：每 3 回合释放一次孢子云（范围 3×3 格，持续 2 回合） |

### 可交互物件

**1. 矿工画板（墙壁旁）**

一块平整的岩壁，上面用菌丝画满了螺旋纹路。不是涂鸦——是**重复的几何图案**，像某种记录。

> 交互文本：「有人在这里画了很久。菌丝的走势精确得像测量过。」

叙事含义：这不是任何已知势力留下的纹路——是**被异化的矿工自己画的**。他们在网络里看到了某种图案，用菌丝把它描在了墙上。

**2. 破损背包（浅坑边缘）**

一个被菌丝半埋的矿工背包。

> 交互文本（第二篇矿工日记）：「第七天。我开始能听懂它们了。不是听懂话——是听懂意图。它们在……等待什么。或者说，等待谁。」

**3. 回声宿主的铭牌（击败后掉落）**

- 拾取时的描述：「一块矿工身份牌。名字已模糊不清。」
- **但当你把它放进背包时，铭牌计数器闪烁了一下——从 1 变成了 2，又变回 1。**

这是视觉污染的第 0 次触发，比主线铭牌计数器（第 5 块时才抖动）更早。如果你先进入了回声裂隙，计数器在捡到第一块铭牌时就开始说谎。

> **视觉差异：** 回声裂隙的闪烁是"快速一闪"（0.15 秒，数字瞬间跳变后恢复）。主线的第 11 块闪烁是"缓慢呼吸式"——数字从 11 呼吸到 12 再回 11，共三个呼吸周期（每个周期约 1.5 秒），颜色偏向淡紫。两次闪烁的视觉差异让玩家意识到"这次不一样"。

**呼应"13 块铭牌"：** 这块铭牌是"多出来的"那块——它和 Boss 掉落的那块被刮掉名字的铭牌是同一对，一个是"多出来的人"，另一个是"被遗忘的人"。

> **二周目种子：** 回声宿主胸口的铭牌，在二周目（NG+）时名字不再模糊——显示的是**玩家的名字**。

### 击败回声宿主的演出

- 不倒地。孢子从胸口（铭牌位置）涌出，躯体像"漏气的皮囊"一样萎缩。
- 萎缩后，坑底的积水反射出微弱的光——光里有一个**人形的倒影**，但不是回声宿主的形状。倒影持续了 2 秒，然后消失。
- 同伴（如果在场）：「……那个影子，比他的身体大。」

**叙事含义：** 这个矿工正在变成网络的节点——他的"存在"已经不再局限于身体的范围。影子比身体大，因为他在网络中的"体积"比在物理世界中的大。

### 技术实现

| 系统 | 新增量 | 说明 |
|---|---|---|
| 关卡 | 新建 `EchoCleft_SubLevel.umap`（15×10m） | 复用 D 区岩壁材质 + A 区蘑菇资产 |
| 敌人（菌丝幼体） | DataTable 新增一行 | 复用菌丝宿主 AI，数值下调 |
| 敌人（回声宿主） | 复用菌丝宿主，新增孢子云技能 | 复用 Boss 战的孢子云 Ability，缩小范围至 3×3 |
| 可交互物 | 2 个（画板 + 背包） | 复用现有文本交互弹窗系统 |
| 演出（倒影） | 坑底积水材质新增参数 | Reflection 参数，击败回声宿主后临时开启 |

## 支线2：孢子平台（Spore Platform）

### 位置与入口

D 区峡谷和 E 区 Boss 场地之间，一条被苔藓半掩的岔路。岔路入口不显眼——只有当玩家靠近时，蘑菇朝向会微微转向岔路方向（0.5 秒的动画，玩家可能注意到，也可能错过）。

**辅助提示：** 如果同伴在场，D 区同伴说出「我感觉……有人在摸我的后脑勺」后，同伴的视线会朝岔路方向偏转一次。

### 空间

5×5m 的圆形平台，被浓密的孢子云完全覆盖。玩家进入后，能见度降至 3 格。平台中央有一块平坦的石头，石头上坐着一个**冥想者**。

### 冥想者

- 外观：菌丝宿主的外观，但姿态是**盘腿坐着**，双手放在膝盖上。
- 行为：**不攻击。** 即使玩家走到它面前，它也不动。不回应交互。
- 如果玩家攻击它：它不反击。受到第一次伤害后"消散"——像被风吹散的孢子。留下一块铭牌，日期是**今天**。
- 如果玩家听完文本后离开，再回来：它仍在原地，说：「你还在。很好。」
- 如果玩家击败 Boss 后带着晶核回来：冥想者沉默。菌丝微微发光，和背包里晶核的脉动同步。不需要额外文本——纯视觉同步。（判断条件：`HasCrystalItem` 布尔值）

### 淡金色文本

玩家进入孢子平台后，不需要按任何键。文本自动出现在屏幕底部，每 10 秒一段。颜色为淡金色，前缀带 `·`（冥想者的"自述"标记）。与 E 区 Boss 孢子云记忆文本区分——孢子云文本前缀为淡金色下划线（"网络的记录"标记）。同一 Widget，不同参数。

| 触发条件 | 文本 |
|---|---|
| 进入平台后 3 秒 | `·` 「你闻到了……铁锈？不，是矿场。你从没来过这个矿场。」 |
| 停留 10 秒 | `·` 「这里有人喊过你的名字。但不是你的同伴。」 |
| 停留 20 秒 | `·` 「你走出去了。然后你又回来了。这是第三次。」 |

**第三段文本的三种读法：**

- **首次玩家：** 困惑——"第三次？我第一次玩啊。"
- **二周目玩家：** 震惊——"它知道。它一直知道。"
- **仔细阅读文档的人：** 这是"庞加莱回归"的最小可行暗示——巨兽的梦中，状态会反复。你已经在巨兽的梦里走过三次。

### 玩家的选择与后果

| 选择 | 结果 |
|---|---|
| 听完三段文本后离开 | 获得"感知"buff（Boss 战命中率 +5%，持续整场战斗，命中时 UI 飘淡金色小字"感知命中"）。冥想者仍在原地 |
| 听到第二段后攻击冥想者 | 冥想者消散，掉落铭牌（日期"今天"）。无 buff |
| 听到第一段后离开 | 无奖励，无惩罚。冥想者保持沉默。角色离开孢子平台时，阴影在原地停留 0.2 秒才跟上——像孢子云有点"黏"。纯视觉异常，无 buff、无文本 |
| 听完三段后攻击 | 冥想者不反击，消散前说：「你每次都会选择这个。」 |

**"每次"——对首次玩家是困惑，对二周目玩家是重锤。**

### 叙事功能

- 这是 Demo 中最"不安全"的空间——没有战斗，但信息密度最高，脆弱感最重
- 将"多周目"从文档设定变成可感知的体验。即使只玩一次，也会感到"有什么地方不对"
- "命中率 +5%"的 buff 是机制奖励，但它的来源是"听完一个疯子的自言自语"——奖励与代价绑定。你为了变强，听了不该听的东西

> **节奏说明：** 孢子平台出口到 E 区 Boss 场地之间，预留 10-15 秒的静默通道。孢子云从浓转淡，能见度从 3 格恢复至正常。没有敌人、没有文本、没有异常——让玩家在下坡走向 Boss 场地的那几步里，有一个消化"这是第三次"这句台词的空隙。不是 cutscene，就是一段空的、安静的路。

### 技术实现

| 系统 | 新增量 | 说明 |
|---|---|---|
| 关卡 | 在 `FungalForest_Showcase.umap` 中增加 5×5m 岔路 + 平台 | 复用孢子云体积 + 石头资产 |
| 冥想者 AI | 复用菌丝宿主外观，新建 `BT_Meditator.uasset` | 从 EnemyBase 改，移除 Attack/Seek 节点，只剩 Idle |
| 文本触发 | 进入体积 → 定时器驱动 3 段文本 | 复用孢子云记忆文本的 UI 系统（屏幕底部淡金色） |
| Buff 授予 | 听完第 3 段 → 给玩家添加 `GE_SporeAwareness`（显示名：感知） | 复用 GAS InitStats 思路，新建 Duration=Infinite 的 GE |

## 玩家角色：叙事滤镜方案

Demo 提供三种固定身份，共享同一套关卡流程（A→B→C→D→E→F），仅在文本/对话上产生差异。玩家通过入口处的简单选择确定身份。

| 身份 | 种族 | 一句话描述 | 与矮人同伴的互动差异 |
|---|---|---|---|
| **调查员** | 人类 | 佣兵公会派遣。任务：调查矿工失踪 | 同伴对他有戒备——"你是公会的人，你们只在乎矿石。"释放后态度软化："但你没有丢下我。" |
| **矿工** | 矮人 | 迟到的矿工——或幸存者。进入森林时他的队伍已经进去了 | 同伴认出他。劫后余生的亲切感——但也因此更容易触发反水（情感绑定越强→感染越容易深入）。释放后同伴说："你来了。我们都在等你来。" |
| **精灵学者** | 精灵 | 来自工业城市。来研究森林生态——不知道下面是矿场 | 同伴对这个"外人"不信任——"你在研究我们？像研究标本？"释放后态度转变："你不是来研究。你是来……理解的。" |

**设计原则：** 不是"独立故事线"（DOS2 式工作量 ×3），而是**"叙事滤镜"**（同一流程 + 文本条件分支 ≈ ×1.3 工作量）。Game.csv 中加 `Role` 条件列即可实现。

## 真菌之主的叙事身份

> 它是第一滴源脉之血凝固后、与地底真菌结合而成的**原始意识**。比螺旋文明更古老。在人类、精灵、矮人出现之前——它就在地底沉睡。没有语言、没有思想——只有一种缓慢的、跨越千年的感知。它记得巨兽的心跳。

**矿工触发了什么：** 矿工挖到了一片穿透真菌之主沉睡层的矿脉。在这个深度，矿石和菌丝互溶。触碰矿石 = 触碰它。矿工开始异化，不是被寄生——是被吸入它的记忆网络。

**真菌之主 vs 矿工的关系：** 真菌之主只有一个。矿工不会变成新的真菌之主——他们变成网络的**节点**。他们的记忆还在，他们通过真菌之主继续存在。BOSS 战不是与一只怪物的战斗——是与一个由矿工记忆编织成的存在战斗。

**击败的意义：** 击败不是消灭——是暂时切断物理锚点。它在更深处继续存在。晶核是它的一块记忆碎片——它在脉动，在被带出森林后继续"记得"你。

| Demo 元素 | 与真菌之主的关系 |
|---|---|
| 矿工日记 | 矿工被网络"记住"时的第一手记录 |
| 菌丝宿主 | 异化中期——正在变成网络的节点 |
| 螺旋纹路 | 螺旋文明后来发现它，试图标记/控制 |
| BOSS 战 | 打断——让古老存在退回更深的地底 |
| 晶核掉落 | 记忆碎片。「此物在你手中脉动，仿佛记得什么」 |
| Boss 掉落的铭牌 | 被刮掉名字的身份牌。和矿工的铭牌同一个模具——但比这十二人更早 |

## 收集物：矿工铭牌

### 设计目的

玩家在 Demo 中一路捡到的矿工身份铭牌，在 F 区汇聚成一个核心矛盾：委托人派了十二个矿工，但铭牌数量是十三。铭牌不是"收集品"——是"证据链"的物证载体。

### 分布

| 位置 | 数量 | 说明 |
|---|---|---|
| B 区营地残骸 | 3 块 | 散落在帐篷周围，部分被菌丝半掩 |
| C 区（战后） | 2 块 | 两个菌丝宿主被击败后，干壳旁各掉落一块 |
| D 区峡谷 | 2 块 | 路边——像是匆忙中掉落的 |
| E 区 Boss 场地 | 3 块 | 散布在场地上 |
| E 区 Boss 掉落 | 1 块 | 真菌之主消散后，地上亮着一块——名字被刮掉了，铭牌微微发热 |
| 同伴脖子上 | 1 块 | B 区营救时，玩家看到矮人脖子上挂着一块。**不可拾取** |

**合计：11（拾取）+ 1（Boss 掉落）+ 1（同伴脖子上看到）= 13**

### 铭牌描述

- **普通铭牌（统一描述，11 块全部相同）：** `一块矿工身份牌。名字已模糊不清。`
- **Boss 掉落的铭牌：** `一块矿工身份牌。和其他十一块是同一个模具。不同的是——上面的名字被刮掉了。不是锈，是有人用东西刮的。触碰到时，微微发热。`
- **同伴脖子上的铭牌（B 区营救时的 UI 提示）：** `他胸前挂着一块金属牌子，生了锈，上面隐约刻着一个名字。`

### 设计要点

1. 铭牌不区分名字——不需要给每块单独起名。名字模糊意味着"他们是谁不重要，重要的是数字对不上"
2. C 区菌丝宿主掉落铭牌 → 玩家第一次将"捡铭牌"和"打菌丝宿主"联系起来："铭牌 = 矿工 → 矿工 = 节点"
3. Boss 掉落的铭牌是唯一特殊的——名字被刮掉 + 发热。暗示这块铭牌的主人比这十二人更早
4. 同伴脖子上的铭牌不可拾取——只在 B 区营救时以 UI 提示形式出现一次。F 区同伴说出时，玩家会想起那一瞬间

## 菌丝网络的场景展现

矿工们没有消失——他们的身体被纳入了菌丝网络。以下是四个展现点，用菌丝、蘑菇和铭牌来暗示身体的存在和转化：

### B 区：菌丝覆盖的身形

> 帐篷外，地面上有一团菌丝覆盖的隆起。菌丝的走势隐约勾出一个趴着的身形——肩膀、脊椎、向一侧弯折的膝盖。旁边的菌丝里半埋着一块铭牌。

### C 区：菌丝宿主（已有）

> 战斗击杀 → 不倒地 → 孢子释放 → 躯体萎缩成干壳 → 2 秒后干壳上长出小蘑菇

### C 区：人面枯树桩（注视者）⭐ 新增

> 空地边缘立着几个枯树桩。木纹拧成了一张脸——不是雕刻，是木纹自己的走势。你移动时，那张脸会慢慢转向你。它不追你。它只是看着你。

**设定解释（内部，不对玩家揭露）：** 菌丝穿过枯木时，网络里矿工的记忆在木纹里"显影"——树桩不是变成了人，是记忆在木头里留下了形状。与 B 区菌丝身形、E 区人形凹陷是**同一逻辑的三个介质变体**（菌丝堆 / 木纹 / 地面凹陷），强化"网络里有人"的暗线，不引入新异常源（单源怪诞铁律不破）。

**"注视"母题链（C 区是拐点）：**
- A 区：侧倒蘑菇菌盖朝向玩家来路——**静态**的注视，第一个不对劲
- C 区：树桩人脸实时转向玩家——注视**第一次动起来**，怪诞梯度升级
- F 区：蘑菇菌盖朝向小路"如在注视"——结尾回响

**设计要点：**
- **摆放：** C 区空地边缘 2~3 个（"围观者"位，强化第一场战斗的被围观/被困感），D 区峡谷补 1 个。密度刻意压低——稀罕才瘆人，多了变搞笑
- **不进战斗：** 无血条、不进先攻队列、体型明显大于菌丝宿主，避免玩家误判为敌人（C 区是战斗教学区，敌人可读性优先）
- **不解释：** 无交互弹窗、无图鉴条目。同伴最多一句 L1 级台词："别盯着它们看。"

**注视行为参数（技术原型已验证 ✅ 2026-07-22，AI 建模 + 引擎内 yaw 跟踪测试通过）：**
- 仅 yaw 轴旋转，角速度上限 20~40°/s，平滑阻尼
- **转速分级：** 小型个体转得稍快，大型个体更慢更懒——越大越迟缓，压迫感越强
- 每个树桩带随机角度偏移 + 独立响应延迟（永远差半拍，避免齐刷刷同转的机械感）
- 超出跟踪半径进入休眠，省性能
- **战斗彩蛋（推荐）：** 战斗中所有树桩转向"当前行动的单位"——它们在看轮到谁了。不解释，让玩家过度解读（过度解读正是"认知的代价"）
- **NG+ 种子：** 二周目其中一个树桩的嘴是张开的（仅模型/贴图差异，不改逻辑）

**制作备注：** 静态有机单体是图生 3D 的甜区（无骨骼、无动画需求），比菌丝人形省一个量级工作量。资产见 `comfyui-asset-design-prompts.md` ENV-C-01。

### D 区：岩壁菌丝脉络

> 峡谷岩壁上，菌丝沿着裂缝蔓延——不是附着，是嵌入。像石头自己长出了血管。几块铭牌被菌丝穿过——穿过那个刻了名字的位置。铭牌和菌丝已经长在一起了。

### E 区：菌丝网络节点

> 场地中央的地面，所有菌丝脉络在这里收束。交汇处有几个浅浅的凹陷，大小和人形接近。菌丝在这些凹陷里长得最密——像是这里曾经有过什么，菌丝不舍得让它空着。

## 同伴：矮人矿工

### 设计动机

Boss 战需要"1 vs 真菌之主"之外的战术层次——一个同伴能在叙事和玩法上同时增加深度。

核心思路：**同伴不是额外的战斗单位，而是 Demo 故事的一部分。** 他在六区中拥有完整叙事弧线：被救→同战→被感染→反水→被释放→成为真相的指证者。

### 基本信息

| 属性 | 内容 |
|---|---|
| 种族 | 矮人（男） |
| 身份 | 失踪矿工之一。B 区被困在菌丝中，玩家靠近时触发解救交互 |
| 职业模板 | 战士系（简易，不需要复杂法术 AI） |
| 战斗控制 | AI 控制，跟随玩家，攻击最近目标，偏好聚集在小怪群 |
| 美术 | 1 套矮人矿工 Sprite（idle/attack/hit/dead），2.5D 纸片人 |

### 完整叙事弧线

```
B 区 — 解救
  营地残骸旁。菌丝缠绕的矮人矿工奄奄一息。
  玩家靠近 → 交互解困。营救时相机拉近，看到矮人脖子上的铭牌。
  提示文本："他胸前挂着一块金属牌子，生了锈，上面隐约刻着一个名字。"
  同伴站起来，拍掉身上的孢子。
  → "还有……六个人在里面。"

  同伴参与小型遭遇战，协助清小怪。

  同伴沉默两秒："那是哈洛德。他上个月还在教我磨镐头。"

D 区 — 异常加深

  真菌之主被击败后，地上掉落一块铭牌——名字被刮掉了。

  同伴沉默。然后对委托人：
```

## Boss 战四阶段设计

Boss 战原本为 1 玩家 vs 真菌之主 + 2 小怪。同伴加入后，战斗变为动态四阶段：

```
阶段一：并肩（~60s）
  玩家 + 矮人 vs 真菌之主 + 2 小怪
  矮人负责清小怪、顶前排。一切正常。

阶段二：反水（~30s）
  触发条件：
    - 优先：Boss 血量 < 60% 且 矮人在孢子云中停留超过 1 轮
    - 保底：Boss 血量 < 30%（无论矮人是否在孢子云中，强制触发）
  触发方式差异：
    - 孢子云触发：菌丝从矮人身上蔓延，他转身，动作自然切换——「被感染」
    - 保底触发：Boss 低血量菌丝网络震荡，菌丝从地面涌入矮人体内——更快更暴力

  矮人头像框边缘出现菌丝纹路。
  他转身，动作帧从"攻击"切成"朝向玩家"。
  最后一句话：
  → "来吧，加入我/我们。"

  矮人暂时成为敌人单位，但比普通敌人弱：
  - HP 只有正常状态的 50%
  - AI 只用基础普攻，不用技能
  - 动作有延迟（菌丝操控 + 他在内心抵抗）

  玩家瞬间变成 1 vs 4（真菌之主 + 2 小怪 + 虚弱矮人）
  压力增加，但不是碾压——矮人故意被设计成虚弱状态

阶段三：释放（~20s）
  矮人的 HP 降到 0 → 不放"死亡红牌" → 触发特殊演出：

  菌丝出体 → 孢子散入空中 → 矮人倒地 → 起身，状态清除

  矮人跪在场地边缘，单手撑地。不再参战。
  他说：
  → "我看到了他们……哈洛德、老詹姆、卡里克……
      他们回不来了。"

  释放效果：
  → 真菌之主短暂失神 1 轮（失去了一个节点）
  → 玩家获得"断裂"buff（攻击力 +30%，持续 2 轮）

阶段四：收尾（~70s）
  玩家 + buff vs 真菌之主 + 残余小怪
  矮人在边缘，活着，但不再参战。
  击败真菌之主 → 晶核掉落 + 一块铭牌（名字被刮掉，微微发热）
```

### 设计原理

**为什么是"反水→释放→增益"？**

- 同伴反水时是虚弱的 → 数值上可控（HP 减半 + 无技能 + 动作延迟）
- 击败他不是杀他 → 是"释放"他 → 和 C 区菌丝宿主的死亡规则一致
- 释放效果帮助玩家 → 不是惩罚，而是奖励玩家"在乎同伴"
- Buff 不是无中生有 → 来自真菌之主失去节点时的震荡

**为什么不用能量条/大招系统？**
- Demo 开发时间紧，不做 5 分钟才会用一次的新系统
- Boss 战才第一次用 → 玩家没学会就死了 → 挫败感

**为什么不是纯剧情杀？**
- 玩家不能亲手打同伴的话，反水没有情感重量
- 情感难度 > 数值难度——这是"你必须亲手打败你救的人"

## Demo 叙事架构（完整流程）

```
A 入口 ── 委托人给任务。
          「十二个矿工，两周前进入的。找到他们——或者找到他们发生了什么。」
          三选一快速职业选择（战士 / 游荡者 / 法师）。法师提供 2 戏法 + 1 个 1 环法术/场战斗。。
          玩家独自进入森林。

          **出生点前方 8m，一棵倒下的蘑菇。**
          菌盖朝向玩家来时的方向——不是朝上，是朝路上。
          玩家靠近 → 按 E → 角色底座阴影闪烁一次（0.2 秒）。
          根据身份，角色说：
            - 调查员：「风是从那边吹来的。菌盖不应该朝这边。」
            - 矿工：「这不对。蘑菇知道有人要来。」
            - 精灵学者：「它在……转向？不，是生长方向。生长方向不会错。」
          
          机制影响：无。纯氛围。但从第 3 分钟开始，玩家知道"规则不对"。

B 走廊 ── 营地残骸 + 矿工日记 + 菌丝覆盖的身形。
          「第三天。蘑菇在跟我说话……它似乎在……学我。」（字迹中断）
          帐篷外：菌丝覆盖的隆起，隐约勾勒出趴着的身形。
          旁边菌丝里半埋着铭牌。搜索营地 → 拾取 3 块铭牌。
          营地残骸旁发现被困在菌丝中的矮人矿工——奄奄一息。
          交互解困 → 相机拉近 → 矮人脖子上的铭牌。
          提示文本："他胸前挂着一块金属牌子，生了锈，上面隐约刻着一个名字。"
          同伴起身，拍掉身上的孢子。
          同伴站直了，从地上捡起一块石头在手里掂了掂——像在确认自己还活着。沉默 2 秒。
          →「还有……六个人在里面。」

C 空地 ── 两个菌丝宿主（被寄生的矿工）。
          同伴参与战斗，协助清小怪。
          战斗 —— AI 不躲避，朝玩家走来。

          **同伴攻击菌丝宿主时，插入 0.3 秒"识别"动画。**
          同伴身体前倾（复用 Hit 帧），像在辨认敌人的脸。
          攻击音效延迟 0.1 秒——他在犹豫。
          如果击杀的是菌丝宿主，同伴不做欢呼动画，站在干壳前 Idle 2 秒。

          击败后：不倒地，孢子从体内释放，躯体萎缩成干壳。
          干壳上长出小蘑菇。干壳旁各掉落一块铭牌。
          拾取 2 块铭牌。

          **同伴台词（条件分支）：**
          - 默认：「那是哈洛德。他上个月还在教我磨镐头。」
          - 如果玩家已捡到 B 区哈洛德的铭牌：「哈洛德的牌子你捡到了……对吧？他……他以前总把牌子挂在脖子上，说怕丢了。」

D 峡谷 ── 墙上螺旋纹路 + 岩壁菌丝脉络。
          菌丝嵌入岩壁裂缝，像石头长出了血管。
          几块铭牌被菌丝穿过——穿过那个刻了名字的位置。
          靠近纹路：影子消失 0.3 秒，嗡鸣频率改变。
          纹路每 6 秒微弱发光一次（脉搏感）。
          同伴的影子也短暂消失。
          →「我感觉……有人在摸我的后脑勺。」回头看了一眼,但没有人。
          拾取 2 块铭牌（路边）。

E BOSS ── 真菌之主。场地中央菌丝脉络收束为巨大节点，人形凹陷。
          Boss 战分为四个阶段：

          【阶段一：并肩（~60s）】
          玩家 + 矮人同伴 vs 真菌之主 + 2 小怪。
          矮人负责清小怪、顶前排。

          【阶段二：反水（~30s）】
          Boss 血量 < 60% 且同伴在孢子云中停留 > 1 轮时触发。
          同伴被感染 → 反水为敌人单位。
          HP 50%，只用普攻，动作有延迟（他在抵抗）。
          最后一句话："来吧，加入我。"

          【阶段三：释放（~20s）】
          同伴 HP → 0，不触发死亡红牌，改为"释放"演出：
          菌丝出体 → 孢子入空 → 倒地起身 → 状态清除。
          同伴退至场地边缘，不再参战。
          "我看到了他们……哈洛德、老詹姆、卡里克……
           他们回不来了。"
          释放效果：真菌之主失神 1 轮 + 玩家获得"断裂"buff（攻击力 +30%，2 轮）。

          【阶段四：收尾（~70s）】
          玩家 + buff vs 真菌之主 + 残余小怪。

          **Boss 战斗日志语言（不可理解化）：**
          - 孢子爆发：「真菌之主想起了疼痛。你感受到了 15 点。」
          - 护甲削弱：「真菌之主忘记了防御。它的外壳变得稀薄。」
          - 复制技能：「真菌之主正在学习你的攻击。它越来越像你了。」
          - 召唤小怪：「真菌之主想起了同伴。它们从地下爬了上来。」
          - 回血：「森林正在把它拉回去。」
          
          **孢子云"记忆"文本（淡金色，屏幕底部）：**
          - 第一次进入：「你闻到了……铁锈？不，是矿场。你从没来过这个矿场。」
          - 第二次进入：「这里有人喊过你的名字。但不是你的同伴。」
          - 第三次进入：「孢子云记得你。它比你先到这里。」
          不影响机制。纯氛围。

          **击败演出重构：**
          真菌之主血量归零 → **不播放死亡动画** → 静止不动。
          3 秒后，它缓慢沉入地下。
          没有"胜利"文本。同伴跪在场地边缘：「它走了。不是死了……是走了。」
          晶核不是在尸体上拾取的——玩家低头时，发现自己**脚边有一颗石头在脉动**。

          击败后掉落「脉动的晶核」+ 一块铭牌（名字被刮掉，微微发热）。
          晶核描述：「此物在你手中脉动，仿佛记得什么。」
          铭牌描述：「一块矿工身份牌。和其他十一块是同一个模具。
          不同的是——上面的名字被刮掉了。不是锈，是有人用东西刮的。
          触碰到时，微微发热。」

F 出口 ── 委托人等在那里。
          「你是第三个回来的。前两个……记不太清了。」
          给报酬。袋子里有金币 + 一块微热的矿石。

          同伴（如果活着）：沉默。然后对委托人：
          →「当初不是只有十二个矿工进来吗？多出来的那个人是谁？」
          委托人站住了。转身离开。

          同伴看着玩家，说：
          →「晶核你留着吧。它……它在等你。」

          玩家走出森林，屏幕淡出。

          **黑屏 3 秒。**
          然后出现手写体文本（便签材质）：
          「你走出森林。包裹里的晶石还是热的。
          你数了数铭牌。十二块。
          你明明记得只捡了十一块。」

          然后才是 Steam 愿望单画面。

          身后蘑菇朝向微微转向玩家。
          嗡鸣消失。完全安静。然后风声。

全剧终。主线约 30 分钟，全探索约 60 分钟。
```

## 边缘情况与体验补丁

以下是设计审查中发现的需要补充的边界情况。属于表现层面问题，可在开发中途逐步补齐，不阻塞白盒搭建。

---

### 补丁一：同伴死亡分支

当前叙事流程假设同伴全程存活。需设计一条"同伴在 C 区战死"的降级路径。

#### 触发条件

C 区小型遭遇战中，同伴 HP 降至 0 → 不触发"释放"演出（那是 E 区专用）→ 同伴倒地，死亡红牌拍下。玩家可以继续战斗，战斗结算不变。

#### 叙事降级

| 区域 | 同伴存活 | 同伴死亡 |
|---|---|---|
| D 区 | 同伴：「我感觉……有人在摸我的后脑勺。」 | 跳过同伴台词。玩家独自走峡谷。菌丝纹路的光脉节奏比正常快半拍——像少了什么在吸收注意力。 |
| E 区 | 四阶段完整（并肩→反水→释放→收尾） | 跳过反水和释放阶段。直接 1 vs 真菌之主 + 2 小怪。Boss 血量下调 20%（少了同伴输出 + 少了释放 buff）。Boss 击败后晶核不变，但在 Boss 沉入地下后，玩家脚边除了晶核还多了一块铭牌——和 Boss 掉落那块位置不同，更靠近场地边缘，像被丢下的。 |
| F 区 | 同伴指证委托人。同伴看玩家：「晶核你留着吧。它……它在等你。」 | 跳过同伴指证。委托人：「你是第二个回来的。第一个……记不太清了。」数量从"第三个"降为"第二个"——暗示同伴算第一个回来的人，但委托人忘了。微热的矿石仍然给玩家。玩家整理背包时，晶核在背包格子里自主脉动了一次——没有声音，没有文本。同伴缺席时，世界对玩家的"回应"。 |

#### 设计原则

- 同伴死亡不惩罚玩家。Boss 血量下调 + 直接跳过反水阶段，整体难度持平甚至略低
- 叙事不降级为"无趣"——同伴不在场时，D/E/F 区用环境细节填补缺失的台词
- E 区多出的那块铭牌不计数——它只是一块破损的身份牌，静静地落在场地边缘。不改变计数器，不改变 F 区结尾文本

### 补丁二：战斗教学触发器

A 区只教了自由探索移动（WASD）。C 区是第一场真正的遭遇战，中间缺少回合制战斗的教学桥。

#### 方案：A 区出口前的"不会反击的敌人"

在 A 区即将进入 B 区的通道处（A 区边缘，玩家必经之路上），放置一只 **孢子虫**：

| 属性 | 内容 |
|---|---|
| 名称 | 孢子虫（Spore Mite） |
| 外观 | 复用小型蘑菇模型，缩小至 0.3 倍，加一个缓慢上下浮动的动画。不需要新 Sprite |
| AI | 无。不移动，不攻击。固定位置 |
| HP | 1 |
| 触发方式 | 玩家靠近到 3m 时弹出半透明 UI 提示 |

#### 教学文本（分两段弹出）

**第一段（靠近时）：**
> 前方有一只孢子虫。按 **Tab** 进入战斗模式。

**第二段（进入战斗后，玩家完成第一次移动）：**
> 选择一个格子移动。靠近目标后，点击它进行攻击。

**击败后：**
- 孢子虫萎缩（复用菌丝宿主死亡演出的简化版——只萎缩不长蘑菇）
- 掉落一块破损铭牌（让玩家建立"战斗掉落 → 铭牌"的认知）
- 铭牌描述：`一块矿工身份牌。比其他的小一圈，边缘有裂口。名字已模糊不清。`（拾取后自动合并，不增加计数器）

#### 设计要点

- 不打断沉浸感。孢子虫是"世界里的生物"，不是"教学 NPC"
- 不掉落不消失——如果玩家忽略它直接走进 B 区，它只是静静地浮动在那里
- 铭牌总数不变。孢子虫掉落的铭牌是"破损的"——比普通铭牌小一圈，边缘有裂口。背包中不单独计数：拾取后自动合并到最后一块普通铭牌中，不改变计数器。F 区结尾文本不变——"你数了数铭牌。十二块"——玩家捡到 12 块（11 普通 + 1 破损 = 计数器显示 12），但物理上存在 13 块铭牌
- 10 秒完成，不拖节奏

### 补丁五：玩家返回已通过区域的行为

线性珠串结构不锁死已通过区域的通道。玩家可以在任意时刻回头走。需要定义回退行为，避免出 bug。

#### 规则

| 行为 | 规则 |
|---|---|
| 已拾取的铭牌 | 不重新生成。拾取位置保留空地面 Decal |
| 已击败的菌丝宿主 | 干壳保留在原地（不消失）。蘑菇继续长在干壳上 |
| 已解救的同伴 | 跟随玩家。如果玩家从 C 区走回 B 区，同伴跟着走，不在营地处重新出现 |
| 已触发的叙事事件 | 日记不再弹出（已读过）。异常蘑菇不再触发底座阴影闪烁（已触发过） |
| 已进入的 Boss 场地 | Boss 战触发后 E 区入口不锁。但如果玩家在 Boss 战胜利后走回 E 区，只看到空的菌丝节点场地——菌丝不再发光，孢子云消散。地上的干壳还在 |
| 委托人 | A 区和 F 区是同一个 NPC。如果玩家从 B/C/D 回到 A 区，委托人站在原地，只有一句通用台词：「调查进展如何？」（无剧情推进） |

#### 不需要的内容

- 不需要回头路对话。不需要"你确定要往回走吗"提示。不需要隐藏区域
- 目标是：回头走不出 bug，但不鼓励回头走

### 补丁六：结束画面的技术实现

当前描述："黑屏 3 秒 → 手写体文本 → Steam 愿望单画面"。以下是技术落地细节。

#### 实现方案

**黑屏：** Widget 全屏黑色背景，使用 `UWidgetAnimation` 做淡入（0→100% opacity，1.5s），而不使用关卡加载/卸载。保留当前关卡在背后渲染（性能无影响——F 区是 10m 小径，场景极简）。

**手写体文本：** 便签材质（复用现有 `M_UI_StickyNote` 材质实例），分三行显示，逐行淡入：

```
你走出森林。包裹里的晶石还是热的。

你数了数铭牌。十二块。
你明明记得只捡了十一块。
```

- 第一行延迟 0s 淡入
- 第二行延迟 3s 淡入
- 第三行延迟 6s 淡入（和第二行一起显示——不覆盖，累积）
- 全部文本显示完毕后停留 4 秒

**愿望单画面：** 文本淡出（1.5s）后，显示一张预渲染静态图：游戏标题 Logo + Steam 愿望单链接的 URL 文本（不是可点击的超链接——Demo 阶段通过 Steam overlay 的默认浏览器处理，或者直接显示文字"在 Steam 搜索 Project_DND 加入愿望单"）。不需要 Steam SDK 集成。

**音效配合（补丁三 #8）：** 黑屏时触发"嗡鸣消失 + 风起"音频。嗡鸣在第 2 秒淡出，风在第 2.5 秒进入。第一行文本出现时（延迟 0s），玩家同时听到风声——"不再有嗡鸣了"。

#### 备选方案（更低成本）

如果 UI 动画开发时间不够：直接切成一张全屏静态图片（PNG），包含手写体文本 + 暗色渐变背景。玩家按任意键后显示愿望单页面。牺牲"逐行淡入"的效果，但不牺牲文本本身。

## 60 分钟版本的核心卖点

> **"一场 60 分钟的完整遭遇——每次偏离主线的探索，都会让你离真相更近一步，但也离安全更远一步。"**

这不是"一个更长的 Demo"。这是一个**有深度选择**的短篇体验。玩家在 60 分钟内会经历：

1. **发现不对劲**（A 区蘑菇）
2. **面对"真相不是别人给的"**（回声裂隙——矿工自己在画螺旋纹路）
3. **建立情感连接**（B 区营救同伴）
4. **面对"你已经被认出了"**（孢子平台——冥想者知道你是第几次来）
5. **亲手打朋友**（E 区反水）
6. **带走一个问题 + 一个谎言**（F 区——委托人说"第三个"，但铭牌数不对；铭牌计数器全程在说谎）

**30 分钟版本展示异常——这个世界不对。60 分钟版本让你亲手触碰真相——而每一次触碰，都在改变你。你不是在"发现"这个世界的秘密，你是在"选择"知道多少。而你知道得越多，身体越开始变得不像自己。**

---

*60 分钟版本是 Project_DND 的"完整体验 Demo"。它不是更长——而是更深。每一次偏离主线的选择，都是玩家自愿支付的"认知的代价"。*
