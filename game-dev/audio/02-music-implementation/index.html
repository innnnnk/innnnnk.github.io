文档定位

本文件是 音频模块总纲 之下的配乐施工图：把 配乐方向文档 的方向性文字，落成作曲能直接下单的资产规格、程序能直接接线的参数表。命名、常量、接口一律以总纲为准；本文件只补充音乐侧实现细节，冲突时以总纲为准并在此标注。

范围： 资产规格（M1–M8 → MUS_*）、三个 MetaSounds 的参数契约、强度映射、垂直/横向切换量化、Boss 四阶段自动化、主题配额检查表、嗡鸣与主题共基频、F 区结尾秒表、NG+ 参数、作曲 Brief、零资产启动方案。

不写： 总线增益结构（04 文档）、SFX 事件目录（03 文档）、UE 类与资产结构（01 文档）、集成排期（05 文档）。

前置事实（决定本文写作顺序）： M1 主题动机未定稿（配乐附录 A 三候选待试听）。按配乐文档要求"动机定稿前所有区域音乐不得开工"，本文所有资产规格为"待 M1 定稿后可立即下单"的锁版规格；在这之前，程序侧按 §12 零资产方案先行接线。全工程仍是零代码、零资产状态（总纲 §前置事实）。

追溯约定：(配乐 §X) = music-direction-design.md 第 X 节；(Demo §X) = fungal-forest-demo.md 第 X 节；【新增】 = 本文新增、需城主确认的设计。

3.4 导出与导入规范（验收前置）

  1. 采样率： tempo-locked 循环统一 44.1 kHz / 24-bit WAV。理由【新增·推导】：63 BPM 在 44.1 kHz 下 1 拍 = 42 000 samples、1 小节 = 168 000 samples（整数），swing 55% = 23 100/18 900 samples（整数）；48 kHz 下 1 小节 = 182 857.14 samples，24 小节累计偏差 ≈3.4 samples（0.07 ms），stems 对齐需额外微淡。单次演出/one-shot 可用 48 kHz。
  2. 循环点： 采样级无缝；尾音（混响/释音）折返叠加到头部（tail-wrap），不加淡入淡出；循环点 RMS 差 ≤0.5 dB、无咔哒、无 DC 偏移；stems 必须同一次分轨 bounce，长度逐 sample 对齐、相位一致。
  3. 格式： 交付立体声 24-bit WAV；引擎导入 P0 循环用 PCM，P1 循环可 PCM（Demo 全量约 300–400 MB）或 Bink/Vorbis q0.8（约 1/10 体积，须复验循环点）。单声道仅允许 one-shot 单音采样。
  4. 响度与余量： 分轨峰值 ≤ -6 dBFS，不做总线限制器；整轨目标 integrated ≈ -18 LUFS、TP ≤ -1 dBTP（待 04 定稿，总纲 §三）。
  5. 验收方法： 每轨连续循环 3 次听测 + 频谱查 D3/D1 锚点 + 时长按小节数核对 ±2 ms；stems 相位用极性反转 null test（残余 ≤ -40 dBFS）。
